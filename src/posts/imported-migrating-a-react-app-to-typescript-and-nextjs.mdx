## Introduction

Hi, I'm Gaurav, a Frontend Developer from India specializing in React.js, JavaScript, and Redux Toolkit. After working for about a year and a half at Hocalwire Labs developing CMS-driven interfaces, I took a temporary break for personal reasons. Now that I am returning to the field, I've chosen to focus on enhancing my skill set before applying for new job roles.

Here is a look at what I am currently focusing on:

## Migrating one of my projects to TypeScript + Next.js

I previously developed FoodFlick, a food-ordering application that utilizes live restaurant data, using plain JavaScript and Create React App. I am now in the process of completely rebuilding it. My goal is to implement TypeScript for reliable type safety and adopt the Next.js App Router to align with the modern routing and rendering practices used by modern tech companies.

## Learning frontend performance optimization alongside it

This migration is more than just a simple syntax update for me. I am treating this project as an opportunity to actively measure and enhance key performance metrics. I want to focus on optimizing Lighthouse scores, reducing bundle sizes, and improving load times rather than just making the code compile successfully.

## What's next

I plan to document my entire journey, sharing insights into what breaks, what challenges me, and the solutions I discover along the way. If you have experience with a similar technical migration or possess recommendations for structuring a Next.js App Router project efficiently, I would highly appreciate your insights.
