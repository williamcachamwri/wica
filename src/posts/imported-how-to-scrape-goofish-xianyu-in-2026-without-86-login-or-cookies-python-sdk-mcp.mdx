**Goofish (`闲鱼` / Xianyu)** is Alibaba's flagship C2C recommerce marketplace — processing over **100M+ monthly active buyers** across vintage mirrorless cameras, PC GPUs, retro handhelds, road bikes, luxury handbags, and anime/ACG collectibles (*guzi* / `谷子`). Because individual Chinese sellers price used gear for fast domestic turnover, street prices on Goofish routinely sit **20%–45% below eBay, Reverb, Mercari JP, or Chrono24**.


Yet if you have ever tried building a Python deal monitor, price-comp dataset, or AI shopping agent for Goofish from outside mainland China, you hit four immediate engineering walls:


**Ephemeral Request Signing &amp; Session Tokens**: Goofish's web and mobile endpoints require short-lived cryptographic request signatures paired with rotating session tokens that expire rapidly.

**Alipay / +86 Real-Name Login Walls**: Unauthenticated keyword search and seller-profile requests on standard web views immediately hit a mandatory Taobao/Alipay QR login gate requiring mainland +86 SMS or passport KYC verification.

**Aggressive Datacenter Anti-Bot Filtering**: Standard cloud IPs (AWS, GCP, GitHub Actions, Hetzner) are immediately blocked or challenged with interactive verification sliders.

**Opaque `m.tb.cn` Share Snippets &amp; Slang**: Sellers share links as raw mobile text (`【闲鱼】https://m.tb.cn/h.xxxx 点击链接直接打开`), and listings use domain-specific Chinese shorthand (`箱说全` = full box &amp; papers, `无拆无修` = unopened/unrepaired, `个人闲置` = personal seller, `吧唧` = anime tin badge) that literal English keyword searches miss completely.


In this guide, we will walk through how to query live Goofish listings, resolve `m.tb.cn` share links, compute CNY-to-USD markdowns, generate 1-click **Superbuy / AllChinaBuy** proxy checkout links, and audit seller **Zhima Credit (`芝麻信用`)** &amp; buyer reviews using the open-source **`goofish-xianyu-api`** Python SDK and **`goofish-xianyu-mcp`** Model Context Protocol server — with **zero Taobao/Alipay cookies**.
